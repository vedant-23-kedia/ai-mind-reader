# Legacy artifacts

Kept for provenance. Nothing here is used by the app or the training scripts.

## models/

The original category-level models: they predicted one of 9 categories
(Animal, Vehicle, Electronic, ...) from 52 attributes, never the object
itself. Superseded in Phase 3 by `models/object_*.pkl`, which predict the
object directly from 141 attributes.

Their reported accuracies — Decision Tree 85.7%, Naive Bayes 92.9%, MLP
92.9% — were measured on a single test split of a 56-row dataset. That is
14 test rows, so 92.9% means 13 of 14. The figures were never meaningful
and should not be quoted.

## plots/

Charts generated from those category models and the original 56-object
dataset. Replaced by `data/plots/`, which is regenerated by
`scripts/train_models.py`.
